# 留白

原生 macOS 中文 TXT 阅读器。阅读窗口只显示文字，没有工具栏、按钮、进度条、边框或阴影。

## 打开

双击 `dist/留白.app`，或将它拖到「应用程序」。支持 macOS 13 及以上，安装包同时包含 Apple Silicon 和 Intel 版本。无需浏览器、Node.js 或额外运行环境。

首次打开可以选择 TXT、拖入文件，或阅读内置示例。支持 UTF-8、带 BOM 的 UTF-16 / UTF-32、GB18030 / GBK。文件上限 30 MB。中文章节与英文 Chapter / Part 标题自动识别，没有章节的文件以「正文」展示。

## 阅读

窗口没有边框和阴影，边缘及四角仍可拖动缩放，文字根据可用宽度自动换行，无横向滚动。拖动顶部或文字旁的空白可移动窗口；按住 Option 也可拖动任意位置。单击空白不会切到后面的应用。滚轮、触控板、方向键均可直接翻页，无滚动动画。缩放时保留阅读位置，页面只显示完整文字行。应用菜单、面板及系统文件选择框使用中文，不改变 Mac 的系统语言。

右键点击正文或按退出键（Esc）打开面板，再按退出键或点击面板外关闭。小窗口打开面板时会临时放大，关闭后恢复原阅读尺寸；在面板中移动窗口后，阅读窗口会跟随新位置。面板提供章节目录、全文搜索、外观和快捷键。搜索结果点击即可跳转，并选中匹配文字。

「快捷键」面板可自定义上一页、下一页按键，默认使用 Page Up / Page Down。点击按键按钮后直接按下单键或组合键，设置立即保存；按退出键取消录入。重复按键及应用已有快捷键会提示冲突。还可以使用空格翻到下一页、Shift + 空格返回上一页；自定义快捷键优先。触控板每次完整滑动只翻一页，忽略惯性，避免意外连续翻页。每页按完整文字行切分，连续翻页不会漏行；下一页后再按上一页回到原页。快捷键仅在纯阅读界面生效，不干扰搜索输入。

「外观」中的「背景透明度」支持 0%（不透明）到 100%（完全透明）。透明度只影响阅读背景，文字保持不透明，设置自动保存。完全透明时可按退出键打开面板。切换纸张主题会保留透明度，「恢复默认」会恢复不透明背景。升级会保留旧版本的字体、颜色及其他设置。

透明状态下四边及四角仍可缩放，顶部可拖动移动窗口。移动到边缘时鼠标会显示缩放提示。为避免 macOS 将完全透明像素处的鼠标事件穿透给其他窗口，整个窗口保留最低 2% 的鼠标响应底色（视觉上接近透明），没有装饰边框或阴影。

| 快捷键 | 功能 |
| --- | --- |
| ⌘ O | 打开 TXT |
| ⌘ T | 章节目录 |
| ⌘ F | 全文搜索 |
| ⌘ L | 听书面板 |
| ⌘ , | 外观设置 |
| ⌘ ⇧ , | 自定义翻页快捷键 |
| Page Up / Page Down（可自定义） | 上一页 / 下一页 |
| Esc | 打开 / 关闭面板 |
| ⌘ = / ⌘ − | 放大 / 缩小文字 |
| ⌘ ⌥ ← / → | 上一章 / 下一章 |
| ⌃ ⌘ F | 进入 / 退出全屏 |
| ⌘ M | 最小化 |
| ⌘ W | 关闭窗口 |
| ⌘ Q | 退出 |

最近 16 页保留排版缓存，往返翻页复用已有页面；缩放、字体或字号变化时自动重新计算。文字颜色和背景调整不改变页码边界。

进度、窗口尺寸、外观和翻页快捷键自动保存，翻页后立即退出也会保存最新位置。重新打开时继续上次阅读。文字保存在 `~/Library/Application Support/cn.liubai.reader/CurrentBook.json`，设置与进度在本机 UserDefaults 中保存。普通阅读不访问网络。

## 听书

打开一本书后，按 `⌘ L` 或在面板中选择「听书」。可以从当前页开始，或继续上次听书；支持暂停、继续、停止，0.75–2 倍播放速度，以及晓晓、云希、晓伊、云健四个中文音色。语音按自然句段切分，提前准备下一段，自动跨章节接读。「跟随朗读翻页」会在每段开始时跳到相应文字，可以关闭后边听边自行翻阅。跳转目录或搜索结果、打开另一本书会停止当前朗读。

音色、速度和听书位置自动保存，退出后不会自动播放，可以在听书面板继续。切换音色后会停止播放，并从这一段开头重新生成。进度按段落位置和段内音频时间记录，播放时每 5 秒保存，暂停、停止及正常退出时立即保存。

听书使用微软 Edge 在线朗读服务，无需 Azure 账号或 API Key；首次生成需要联网，待朗读文字会发送给微软。音频按内容和音色缓存到 `~/Library/Caches/cn.liubai.reader/Listening`，重复播放复用缓存，调整倍速无需重新生成。缓存上限约 256 MB，自动清理较早使用的音频。缓存仍在时，可离线播放相应段落，遇到未缓存内容会提示网络错误，并保留可重试的位置。

客户端参考 [edge-tts](https://github.com/rany2/edge-tts) 公开的 Edge Read Aloud 协议，以 Swift 原生实现 WebSocket 请求、音频帧解析及时间校准，不包含 Python 包或运行时。当前服务无需付调用费，但它属于 Edge 浏览器的在线服务，不提供第三方应用的长期可用性或无限用量保证；接口变化可能需要更新客户端。协议版本信息集中在 `Sources/Liubai/EdgeSpeech.swift`。

## 开发

Swift + SwiftUI + AppKit，不依赖第三方包。只需 macOS 和 Xcode Command Line Tools。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open dist/留白.app
```

构建脚本生成通用 `.app` 和 `.zip`，使用本地临时签名。安装了完整 Xcode 时也可以使用 `swift test` / `swift run`。分发到其他 Mac 如需消除 Gatekeeper 的首次打开提示，需要 Apple Developer ID 签名及公证。

分页性能基准（本机、4.55 MB 合成中文 TXT，往返翻页 100 次）可运行 bash scripts/test.sh --benchmark。基准只测量打开准备与分页处理，不包含屏幕绘制耗时。
