# 留白

原生 macOS 中文 TXT 阅读器。阅读窗口只显示文字，没有工具栏、按钮、进度条、边框或阴影。

## 打开

双击 `dist/留白.app`，或将它拖到「应用程序」。支持 macOS 13 及以上，安装包同时包含 Apple Silicon 和 Intel 版本。无需浏览器、Node.js 或额外运行环境。

首次打开可以选择 TXT、拖入文件，或阅读内置示例。支持 UTF-8、带 BOM 的 UTF-16 / UTF-32、GB18030 / GBK。文件上限 30 MB。中文章节与英文 Chapter / Part 标题自动识别，没有章节的文件以「正文」展示。

## 阅读

窗口没有边框和阴影，边缘及四角仍可拖动缩放，文字根据可用宽度自动换行，无横向滚动。拖动顶部或文字旁的空白可移动窗口，单击空白不会切到后面的应用。滚轮、触控板、方向键均可直接翻页，无滚动动画。缩放时保留阅读位置，页面只显示完整文字行。应用菜单、面板及系统文件选择框使用中文，不改变 Mac 的系统语言。

右键点击正文或按退出键（Esc）打开面板，再按退出键或点击面板外关闭。面板提供章节目录、全文搜索、外观和快捷键。搜索结果点击即可跳转，并选中匹配文字。

「快捷键」面板可自定义上一页、下一页按键，默认使用 Page Up / Page Down。点击按键按钮后直接按下单键或组合键，设置立即保存；按退出键取消录入。重复按键及应用已有快捷键会提示冲突。每页按完整文字行切分，连续翻页不会漏行；下一页后再按上一页回到原页。快捷键仅在纯阅读界面生效，不干扰搜索输入。

「外观」中的「背景透明度」支持 0%（不透明）到 100%（完全透明）。透明度只影响阅读背景，文字保持不透明，设置自动保存。完全透明时可按退出键打开面板。切换纸张主题会保留透明度，「恢复默认」会恢复不透明背景。升级会保留旧版本的字体、颜色及其他设置。

透明状态下四边及四角仍可缩放，顶部可拖动移动窗口。移动到边缘时鼠标会显示缩放提示。为避免 macOS 将完全透明像素处的鼠标事件穿透给其他窗口，整个窗口保留最低 2% 的鼠标响应底色（视觉上接近透明），没有装饰边框或阴影。

| 快捷键 | 功能 |
| --- | --- |
| ⌘ O | 打开 TXT |
| ⌘ T | 章节目录 |
| ⌘ F | 全文搜索 |
| ⌘ , | 外观设置 |
| ⌘ ⇧ , | 自定义翻页快捷键 |
| Page Up / Page Down（可自定义） | 上一页 / 下一页 |
| Esc | 打开 / 关闭面板 |
| ⌘ = / ⌘ − | 放大 / 缩小文字 |
| ⌘ ⌥ ← / → | 上一章 / 下一章 |
| ⌃ ⌘ F | 进入 / 退出全屏 |
| ⌘ M | 最小化 |
| ⌘ W | 关闭窗口 |
| ⌘ Q | 退出 |

进度、窗口尺寸、外观和翻页快捷键自动保存，重新打开时继续上次阅读。文字保存在 `~/Library/Application Support/cn.liubai.reader/CurrentBook.json`，设置与进度在本机 UserDefaults 中保存。应用不访问网络。

## 开发

Swift + SwiftUI + AppKit，不依赖第三方包。只需 macOS 和 Xcode Command Line Tools。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open dist/留白.app
```

构建脚本生成通用 `.app` 和 `.zip`，使用本地临时签名。安装了完整 Xcode 时也可以使用 `swift test` / `swift run`。分发到其他 Mac 如需消除 Gatekeeper 的首次打开提示，需要 Apple Developer ID 签名及公证。
